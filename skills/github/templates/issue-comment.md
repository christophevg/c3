# Issue Comment Templates

## Status Updates

### Accepted to Backlog

```markdown
Reviewed and accepted. Added to TODO.md.

**Priority:** {P1-P4}
**ETA:** {estimated timeframe}
```

### Needs Research

```markdown
Needs evaluation for technical feasibility.

**Questions:**
- {Question 1}
- {Question 2}

Will update once research is complete.
```

### Blocked

```markdown
**Status:** Blocked

This issue is blocked by:
- #{blocking-issue-number}: {blocking issue title}

Will proceed once blocker is resolved.
```

### Won't Implement

```markdown
**Status:** Won't implement

Closing: {reason}

**Alternatives:**
- {Alternative 1}
- {Alternative 2}

Thank you for the suggestion.
```

## Progress Updates

### Starting Work

```markdown
**Status:** In Progress

Starting work on branch `{branch-name}`.

{Additional context about approach}
```

### PR Created

```markdown
**Status:** PR Ready

PR created: #{pr-number}

{Brief description of implementation approach}
```

### Completed

```markdown
**Status:** Completed

Closed via #{pr-number}.

{Brief summary of solution}
```

## Clarification Requests

```markdown
Thank you for this issue.

Could you provide more details about:

1. **Expected behavior:** {what should happen}
2. **Steps to reproduce:** {how to trigger the issue}
3. **Environment:** {OS, version, etc.}

This will help us investigate and resolve the issue faster.
```

## Review Request

```markdown
**Status:** Ready for Review

PR #{pr-number} is ready for review.

**Summary:**
{Brief summary of changes}

**Testing:**
{How to test the changes}
```
